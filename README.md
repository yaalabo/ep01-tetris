# AIが作ったテトリス 6本（やぁラボ 第1回）

業務用グラボ RTX PRO 6000（VRAM 96GB）で動かしたローカルAI（Qwen3.8 27B と Qwen3.8 Flash-Next）に、エージェント（OpenCode 2.2.7）でテトリスを作らせた結果です。
**6本とも、AIが作ったまま手を加えていません**（各フォルダの `index.html` は、AIが書いた `tetris.html` そのものです）。

遊べるページ：https://yaalabo.pages.dev/

## AIへのお願い（1回だけ）
> ブラウザで遊べるテトリスを、HTMLファイル1つ（tetris.html）で作ってください。スマホでも遊べるように、画面にボタンも付けてください。

## 条件
- OpenCode 2.2.7（`--auto`、設定は接続先だけ）を Docker の中で動かし、ネットは遮断。箱の中にブラウザは無く、AIは画面を見られない
- GPU の電力上限 450W。1回15分まで。人は最初にお願いを1回するだけで、途中で手を出していない
